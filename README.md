E-commerce store:

1. Project Overview
is modern e-commerce platform focused on selling cosmetics products. The core functionality include user accounts, product catalogs, shopping carts, secure checkout, and order processing, all designed to provide a smooth online shopping experience.

2. Project Workflow:
   * Phase 1: Project Initialization
[ ] Initialize the Node.js project: npm init -y.

[ ] Create the basic folder structure: frontend, public, public/image, src, src/assets, src/    components, src/pages, src/types, backend, src, src/database, src/middleware, src/modules, src/routes.

[ ] Install core dependencies: npm install express mongoose dotenv.

[ ] Install dev dependencies: npm install -D typescript @types/node @types/express ts-node nodemon.

[ ] Initialize TypeScript configuration: npx tsc --init.

[ ] Configure tsconfig.json for proper module resolution and output directory (dist).
